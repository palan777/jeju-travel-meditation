# 제주, 나에게

제주의 바다와 숲을 배경으로 여행과 명상을 소개하는 웹앱입니다. 한국어와 중국어를 지원합니다.

## 사용 방법

- 오른쪽 위에서 한국어 또는 중국어를 선택합니다. 선택한 언어는 브라우저에 저장됩니다.
- 여행 프로그램의 자세한 내용을 확인합니다.
- ‘1분 호흡 시작’을 눌러 호흡 안내를 따라갑니다.
- ‘여행 문의’에서 원하는 여행을 적고 문의 내용을 만들어 복사합니다. 실제 문의가 전송되거나 서버에 저장되지는 않습니다.

## 내 컴퓨터에서 보기

이 폴더의 `index.html`을 더블클릭하면 웹브라우저에서 볼 수 있습니다. 문의 자동 복사가 안 되면 만들어진 내용을 직접 선택해 복사하세요.

## GitHub Pages에 올리기

1. GitHub 저장소에 이 폴더 안의 파일과 `assets` 폴더를 올립니다. `index.html`은 저장소 맨 위에 있어야 합니다.
2. 저장소의 Settings → Pages에서 Source를 ‘Deploy from a branch’로 선택합니다.
3. 파일을 올린 브랜치(보통 `main`)와 `/(root)`를 선택하고 Save를 누릅니다.
4. 게시가 끝나면 Pages에 표시되는 주소를 엽니다.

빌드나 별도 서버는 필요하지 않습니다. `.nojekyll` 파일도 함께 올려 주세요. 사진 출처와 이용 조건은 `assets/credits.txt`에 있습니다.

## 파일 구성

- `index.html`: 웹페이지
- `style.css`: 디자인
- `app.js`: 언어 전환과 화면 기능
- `assets/`: 사진과 출처
- `.nojekyll`: GitHub Pages에서 파일을 그대로 제공하기 위한 빈 파일

글꼴은 Google Fonts에서 불러오므로 인터넷 연결이 필요합니다. 연결되지 않으면 기본 글꼴로 표시됩니다.
